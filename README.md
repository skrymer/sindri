# Sindri

A personal React component library — headless primitives, Tailwind styling, design tokens, built to be easy for both people and AI agents to use.

> **Public for reference; not intended or supported for external use.** Sindri exists for my own projects and as a showcase. Issues and pull requests from outside aren't monitored, and APIs change without notice.

Named after the dwarf smith of Norse mythology who forged Mjölnir and Draupnir.
